# Agent Note：岛屿进化

状态：已实现

[English](2026-09-21-island-evolution.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §51 将「岛屿进化」列为 P2 #21，§7 定义岛屿模型：多个逻辑岛屿——保守、性能导向、成本导向、新奇导向、对抗导向——并在其间定期迁移强候选，因为没有多样性保持，harness 会收敛到第一个"足够好"的技能并停止发现替代方案。harness 此前没有单技能并行进化轨道的概念，没有候选在轨道间移动的记录，也没有决定迁移何时到期的调度。

## 决策

新增一个包 `dsh-evolution-islands`，持有按技能持久化的进化轨道及其迁移记录：

1. **轨道被注册，刻度被推进。** 操作者以 §7 五个目标之一（`ISLAND_OBJECTIVES`）注册岛屿；重复岛屿 id 响亮拒绝。优化器在 `stageWrite` 之后立即通过可选存储缝把技能的头岛屿——最新注册者——推进一个代际刻度；尚无岛屿的技能是静默空操作，记录失败只记警告而不让优化失败。
2. **迁移被记录，而非执行。** `migrate` 校验两个岛屿都存在且服务同一技能，然后以全新迁移 id 记录带原因（`schedule` | `elite` | `diversity`）的移动，因此候选可以反复迁移，每次移动都留在记录中。§58.12 保持信任只记录不强制：这里没有任何机制自行移动候选。
3. **调度是纯函数且可配置。** `migrationDue` 把未迁移岛屿锚定在注册时刻、已迁移岛屿锚定在最后一次迁移时刻，再与节奏比较。节奏是带一天默认值的校验 `Config` 字段；`schedule(skill?)` 渲染每个岛屿及其上次迁移与到期标志。
4. **一个持久域，一个命令面。** `evolution_islands` 域（v1）含 `islands` 与 `migrations` 两张表。`/islands` 列出调度、注册轨道、记录迁移（默认原因 `schedule`）并读取迁移日志。本包挂载进 web-app profile（只写自己的域，不触及任何模型提示词）。

## 备选方案

- 把岛屿并入人口存储——否决：人口只跟踪每技能一条谱系；岛屿是带独立目标与自身迁移历史的并行轨道，是另一种形状，塞进候选记录会过载。
- 按调度自动迁移——否决：§58.12 保持信任只记录不强制；调度只标记到期迁移，由人（或未来的自动化）执行移动。
- 为变异算子或评估器制定按目标策略——否决：§7 的目标目前只是被记录的词汇；让每条轨道以不同方式引导算子、种子或评估器需要一个所有者，已记为暂缓。

## 后果

- 多样性保持现在可见：`/islands list writer` 显示该技能的轨道、代际与哪些迁移到期，操作者因此能同时维持几个候选策略，而不是只有一个胜者。
- 迁移历史持久且可审计：每次移动记录来源/去向、候选、技能、原因与时刻，且候选的重复迁移在表中永不冲突。
- 优化器保持解耦：记录可选且失败隔离。

## 与计划的偏差

除常规外没有。头选择被抽成纯函数 `headIsland`（最新注册；相同时刻保持输入顺序，与人口存储的 `headOf` 一致）。私有表字段命名为 `islandTable`/`migrationTable`，因为名为 `islands` 的私有字段会在实例上遮蔽公开的 `islands()` 方法。

## 途中修复

名为 `islands` 的私有字段与公开 `islands()` 方法冲突，使每次 `store.islands(...)` 调用都报「不是函数」；字段已改名。初稿按岛屿 id 排序同一毫秒的注册，使测试中的头选择依赖时序；已移除该平局规则以对齐 `headOf`，并在存储测试中插入毫秒间隔使头保持确定。调度测试起初期望目标岛屿的上次迁移保持 null，但一次迁移同时触及两端；断言现在期望两端都有该迁移，并以第三个未触及岛屿覆盖 null 分支。

## 测试

岛屿辅助函数：按注册时刻与按上次迁移锚定的迁移到期、精确节奏边界、按最新注册且同刻按输入顺序的头选择。存储：零代际注册与重复拒绝、有/无岛屿时的头推进、含未知岛屿与跨技能拒绝及重复移动的迁移记录、列表排序/过滤/副本脱离、含上次迁移与到期标志的调度渲染、配置节奏、经 zod 规范的重启持久化、启动前读取。优化器钩子：已挂载存储推进技能头岛屿、未挂载时暂存不变、失败存储记录警告。`/islands`：未挂载、语法用法、含错误传播的注册、含默认与显式原因及错误传播的迁移、调度列出、迁移日志、空调度。13 个岛屿测试、3 个新优化器测试、4 个新命令测试通过；新包语句/分支/函数/行 100%，优化器保持 100%。

## 顺带不动

迁移被记录，而非执行：调度按 §58.12 只标记到期迁移，移动候选仍是操作者的职责（包内 Known Limitations 有说明）。一个代际刻度只落在头岛屿上；技能全部轨道的并行刻度未跟踪。五个目标只是标签而非策略：目前没有轨道以不同方式引导变异算子、种子或评估器。
