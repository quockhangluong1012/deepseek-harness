# Agent Note：依赖感知血缘

状态：已实现

[English](2026-09-22-dependency-aware-lineage.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §34 要求每个评估结果都记录依赖版本，因为更换评估器会使历史指标失效，更换检索会使旧用量指标不可比；§36 要求性能提升时记录说明是哪个变更导致的；§48 要求进化实验可复现。两个更早的 note 已在优化器自己的台账上闭合了部分环路——[依赖感知进化](2026-09-16-dependency-aware-evolution.zh.md)把 scorer 版本打进实验键，[制品血缘与因果归因](2026-09-16-artifact-lineage.zh.md)记录了改动规模计数——但两者都没有留下实验运行时完整依赖集合的独立记录，没有任何检查在信任指标差异前比较两个结果是否同口径，没有消融说明两个变更中是谁带来了收益，也没有种子记录让运行可重放。

## 决策

新增一个包 `dsh-evolution-lineage`，持有带可比性与归因的持久化依赖版本实验信封：

1. **每个受评候选人都是一个信封。** `record` 按实验标识存储假设、候选人、算子、任务、测量三元组、结论、回归、拒绝原因、经验、七个依赖版本（prompt、skill、retriever、evaluator、model、tool、env）与种子，并打上记录时刻。
2. **可比性在读取时推导。** `compare` 报告配置的比较键中版本不同的键——默认 skill、evaluator、retriever、model——当且仅当没有变化时成立；未定义版本对上已记录版本也算变化，因此未知依赖下测得的实验永远不会悄悄参与比较。比较是已记录事实而非门控（§58.12）。
3. **归因是纯函数。** `attributeImprovement` 根据四个臂做双因素消融归因：联合臂必须通过才有任何归属，两个单臂都通过则归于两者，一个通过则归于它，单臂都不通过则归于交互——没有任何一个变更能独自复现联合收益，因此单个臂不配独占功劳。
4. **每个信封都可重放。** `replay` 返回脱离存储的信封，其种子可复现该运行（§48）。一个持久域 `evolution_lineage` v1 含一张按实验标识键控的 `experiments` 表；非法行会在域打开时大声失败。

## 备选方案

- 把完整依赖集合扩进优化器台账——否决：台账在优化器治理下记录按运行结果；信封存储是带自有比较键配置的跨运行可比性之家，而优化器包已拥有它对其他存储的暂存写入治理。
- 从人口存储的父代关系推导可比性——否决：父代关系说明哪个候选人源自哪个，没说明各自在什么依赖版本下测得；血缘回答传承，信封回答测量条件。
- 把不可比强制为晋升门控——否决：§58.12 保持信任只记录不强制；存储只报告结论，拒绝不可比的晋升仍是操作者的职责。
- 三因素与析因消融——否决：双因素已覆盖 §36 想要的单变更纪律；更大的设计在没有当前消费者的情况下只会增加臂数。

## 后果

- 指标差异现在可信：操作者在相信一次胜利意味着更好的技能而非新的评估器之前，`compare` 会点名到底是哪个依赖动了。
- 改进现在可归因：消融结论说明是一个变更、两个变更，还是只有它们的交互复现了联合收益。
- 实验现在可重放：种子随信封同行，因此任何已记录运行都能从其记录复现。

## 与计划的偏差

除常规外没有。比较键默认值（skill、evaluator、retriever、model）跟随 harness 今天实际版本化的 §34 依赖；prompt、tool 与 env 随信封同行，等版本面存在时按配置加入可比性。

## 途中修复

`Config` 模式的 `z.enum(DEPENDENCY_KEYS)` 需要 `as const` 元组；普通 `readonly DependencyKey[]` 会被 zod 的 enum 签名拒绝。测试启动向 `ctx.plugin` 显式传 `{}`，因为 Cordis 对带 `static Config` 模式的服务会传 `undefined` 配置，与停滞与岛屿存储的先例相同。

## 测试

纯函数：规范键顺序、相同记录、双向未定义对字符串、按给定顺序报告、键范围、可比成立/不成立及范围、全部五种归因结果（联合失败为 none、both、a、b、interaction）。存储：记录时刻、按最新优先加实验 ID 平局打破的列表、技能过滤、副本脱离、信封命中与未知、比较可比加变化键加范围外键仍可比加任一未知、重放脱离加种子完整加未知、经 zod 规范的重启持久化、启动前读取。11 个血缘测试与 8 个存储测试通过；新包语句/分支/函数/行 100%。

## 顺带不动

存储只记录可比而不强制可比：拒绝不可比的晋升仍是操作者的职责（§58.12，包内 Known Limitations 有说明）。归因只覆盖双因素消融；三因素与析因设计推迟。退役的比较保持不可比，直到操作者记录新的信封——不自动重测。
