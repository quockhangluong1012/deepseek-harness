# Agent Note: 睡眠时计算

Status: implemented

[English](2026-09-22-sleep-time-compute.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §25 定义睡眠时计算（机制族 W）：空闲时间预期可能出现的未来任务，预计算摘要、检索结构与候选计划，把推理产物缓存下来，建模为离线成本相对预期未来节省加质量收益的经济优化。harness 此前没有任何关于空闲时间预期的持久记录，没有缓存的推理产物，也没有说明哪种预计算能回本的策略——于是安静的时段一无所产，任何未来的预计算都只能盲目花钱。

## 决策

新增一个包 `dsh-evolution-sleeptime`，持有持久化的预期任务及其上推导出的经济计划：

1. **预期是幂等更新的持久事实。** `anticipate(input)` 按标识存一个任务，带可能性、预期查询数与单查询节省；重复预期就地刷新期望。`tasks(domain?)` 按可能性优先、任务标识升序打破平局列出。
2. **值不值得是对预期净收益的严格不等式。** `expectedNet` 把节省按可能性加权再减去估计的离线成本；`decideWorth` 要求严格为正的净收益，因为零净收益等于把空闲时间花在无用功上。理由点名各个数字，因此 `/sleeptime` 渲染永远不必解释两遍算术。
3. **计划在离线预算内贪心。** `planFor` 只保留值得的决策，按净收益降序、任务标识升序打破平局，在累计估计成本仍能装进预算时取用。`plan(cost?, budget?)` 两项都默认取自带校验的配置（`defaultEstimatedCostTokens` 2000、`maxOfflineTokens` 50000），且只覆盖尚无缓存产物的任务。
4. **产物自己记账。** `precompute(input)` 按调用者选定的标识为已知任务缓存一份产物——未知任务大声拒绝——从零命中、零节省起步。`hit(artifactId, occurrences)` 对消耗该产物的已记录轮次记账，因此 `savingsOf` 在预计算回本前保持为负。`evolution_sleeptime` 域含 `tasks` 与 `artifacts` 两张表；[睡眠时驱动者注记](2026-09-22-sleeptime-driver-and-workflow-axis.zh.md) 记录了取代操作者驱动 `hit(artifactId, savedTokens)` 入口的心跳遍历与记账游标。

## 备选方案

- 从 dreaming 周期的候选中推导计划——否决：dreaming 把重复的过往观察固化为记忆（§5），而睡眠时计算赌的是可能的未来；一个读失败，一个读可能性，合并会把两个不同主题绞进同一个调度。
- 现在就强制按种类的成本估计——否决：`plan` 把每次预计算都按同一估计成本计价；按种类的成本模型是实在工作，需要先有测得的离线花费，已记为限制。
- 发布时就按价值衰减淘汰产物——否决：保留需要域上的生命周期逻辑，而消费者尚不存在；存储先累积，缺口已文档化。

## 后果

- 空闲时间现在可计划：`plan()` 准确点名今晚离线预算该给哪些预期任务、按什么顺序，安静时段不再一无所产。
- 每份缓存产物都带回本账本：命中与已省 token 相对离线成本，无需任何模型调用，经 `artifacts()` 可见。
- 心跳的安静节拍就是触发器：[驱动者注记](2026-09-22-sleeptime-driver-and-workflow-axis.zh.md) 注册了预期遍历，因此空闲时间是自动的，而不只是可计划的。

## 与计划的偏差

除常规外没有。初稿让 `plan` 覆盖全部任务；现在只覆盖尚无缓存产物的任务，因为给已有产物的任务重复预计算正是预算策略必须拒绝的第一种浪费。

## 途中修复

带 `scope: z.string().optional()` 的 zod 任务行在 `exactOptionalPropertyTypes` 下不满足 `AnticipatedTask`：推导出的 `string | undefined` 不可赋给 `scope?: string`，因此两个任务接口现在都声明 `scope?: string | undefined`。`KvTable.entries()` 返回没有 `.map` 的 `IterableIterator`，因此缓存任务集合先展开。测试启动向 `ctx.plugin` 显式传 `{}`，因为 Cordis 对带 `static Config` 模式的服务会传 `undefined` 配置。

## 测试

纯函数：含零可能性与零成本的净收益数学、恰好为零的值界与理由内容、含丢弃的计划排序、平局打破、贪心预算装入与溢出、空计划、双向的节省符号。存储：含与不含 scope 的预期幂等更新/时间、任务排序/过滤/副本脱离、未知任务预计算抛错、冻钟平局下的产物过滤/排序、未知产物的记账抛错、默认与显式预算下跳过已缓存任务的计划、经 zod 规范的重启持久化、启动前读取。本包的四个套件通过，`src/` 下每个文件的语句、分支、函数与行四项均达 100%；[驱动者注记](2026-09-22-sleeptime-driver-and-workflow-axis.zh.md) 记录了在其之上新增的遍历与记账用例。

## 顺带不动

存储只记录，从不自己生成产物：驱动者缓存的是其源存储记录下的复现，而不是撰写的散文。一种估计成本为所有预计算计价；按种类的成本需要测得的成本模型。缓存产物累积，无淘汰。
