# Agent Note: 知识图谱记忆为作用域已知之物建立索引

Status: implemented

[English](2026-09-13-evolution-graph.md) | 中文

## 问题

Harness 中既有的每一条召回路径都在匹配文本：排名检索找出文本与查询相近的会话，演进简报只携带一条命中的召回。没有任何东西能回答关于结构的问题——谁参与过某个项目、某个项目依赖什么——因为没有存储保存过一个作用域所谈论之物之间的连接。

规范要求带实体关系与基于图的搜索的图谱记忆。构建它引出了一个规范没有回答的问题：图谱从何而来——harness 没有实体抽取器，而从零手写命名实体识别恰恰是本仓库宁愿花一次模型调用来避免的那类工作。

## 决策

`@deepseek-ai/dsh-evolution-graph` 提供 `ctx.evolutionGraph`：按作用域持久化的实体与有向关系，配有有界遍历与一次确定性提取。

图谱只保存标签、种类与关系名——绝不保存关系读自哪一句话。身份即大小写折叠并去空白后的标签，因此 `Project X` 与 `project x` 是同一实体；关系名被归一化为小写蛇形；边的键由源、关系与目标三者共同构成。首次出现则插入，重复出现则提升该边计数并更新其 `lastAt`；再次见到的实体保留首次标签，同时补上此前缺失的种类。

提取是一次 `temperature: 0`、`purpose: 'evolution-review'` 的调用，其答案必须是 JSON。该答案跨越一条线上边界，因此在写入任何内容之前先被校验：无法解析的 JSON、非对象、缺少 `triples` 数组、答案中出现工具调用，以及失败或被中止的收尾，全部拒绝；被拒绝的提取不写入任何内容。

读取是在同一条记录上的三种遍历：`answer` 从找到的实体沿单个具名关系向外走，`expand` 双向广度优先展开并报出每一跳的关系，`find` 按标签子串定位实体并按连接数排序。两个上界——`maxNodes` 与 `maxEdges`——都在写入时生效：饱和的作用域仍能凭已知内容作答，而不是让调用方失败，并在 `skipped` 中报告丢弃的数量。

`dsh-command-evolution` 中的 `/graph` 是随包提供的消费者：`/graph "<实体>"` 列出连接，`/graph "<实体>" <关系>` 回答单个关系。实体需要加引号，因为标签可能含空格；多出的未加引号词会报用法错误，而不是悄悄截断名称。

## 考虑的替代方案

**让提取搭上评审器既有的调用。** 评审器每个受门控的回合已经做一次确定性调用，因此图谱本可以由同一个答案填充，而不必新增第二条路径。它输在耦合上：那段提示的契约是一份替换用的经验文档，把它扩大到"文档加三元组"，会让此后每一次对经验提取的改动同时成为对图谱提取的改动。图谱自有的调用让二者各自独立版本化，而开发备注把这一权衡记为待定方向，而非已定决策。

**从零手写命名实体识别。** 一个依赖或一套启发式本可以在不调用模型的情况下找出实体，让提取免费。那恰是本仓库一贯拒绝手写的工作：从散文里抽取关系需要世界知识，而为此引入的依赖会是一个为单个特性服务的大表面。`temperature: 0` 的调用直接返回结构。

**把源句存在每条边上。** 保留关系读自哪句话，能让调用方审计一条三元组。它同时也会让图谱成为转录的第二份副本，无界增长并重复会话日志已经保存的材料；图谱是作用域已知之物的索引，因此只保留三元组。

**达到上限时淘汰连接最少的节点。** 在上限处拒绝新实体会让长寿命作用域停止学习新东西。淘汰能继续接纳它们，代价是悄悄遗忘调用方可能仍会遍历到的关系——那比有界且被报告的拒绝更糟。

## 后果

现在可以向一个作用域询问结构，并从一份有界索引作答，而不必重读转录；提取边界把模型的畸形答案挡在持久存储之外。

权衡记录在包 README 中：关系不做语义去重（`worked_on` 与 `workedOn` 是两个关系）；关系永不被移除；遍历是无向的，因此入边会以关系名而非其反向名报告；上限是拒绝而非淘汰。

本包交付是完整的：一份定义、一个消费者命令、喂养它的提取，以及一个生产者。与 `dsh-evolution-heartbeat` 一起挂载时，图谱会缓冲每个作用域内用户与助手消息的文本，并注册 `evolution-graph-extract` 任务，提取自上次运行以来累积的内容——[图谱与向量的融合](2026-09-15-graph-vector-fusion.zh.md)一文记录了该设计及其陈旧性边界。

关系的计数仍然只是频次、也仍然永不被移除，同时记录现在还持有一层[声明/证据层](2026-09-22-claim-evidence-graph.zh.md)：事实携带其来源，矛盾压低其信念，而取代它的声明使被取代的那条退役。
