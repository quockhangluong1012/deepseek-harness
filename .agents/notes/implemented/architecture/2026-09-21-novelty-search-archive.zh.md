# Agent Note：新奇度搜索档案

状态：已实现

[English](2026-09-21-novelty-search-archive.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §51 将「新奇度搜索」列为 P2 #22，§31 定义它：奖励有意义的差异候选而不只是高分候选，因为没有多样性压力，harness 会收敛到第一个"足够好"的技能并停止发现替代方案。优化器已有按基线的新奇度（`noveltyOf`：候选指令行中起始正文未携带的比例），并在幸存者选择中融合新奇度，但没有任何持久的东西记住技能此前见过什么，因此"差异"只能相对单次运行的单一参考体测量，永远无法相对技能的全部历史。

## 决策

新增一个包 `dsh-evolution-novelty-search`，持有按技能持久化的行为描述符档案：

1. **每次暂存写入对应一条档案条目。** 优化器在 `stageWrite` 之后立即通过可选存储缝记录胜者的行为描述符：条目 id 即暂存写入 id，描述符即胜者的去重规范化指令行（`descriptorOf`，从优化器的新奇度模块导出）。记录失败只记一条警告，绝不让优化失败。
2. **档案新奇度基于 Jaccard 且是纯函数。** `similarity` 是两个特征集合的 Jaccard 相似度（两个空集为 0）；`archiveNovelty` 是 1 减去描述符与任意档案条目的最大相似度——无特征描述符为 0，空档案的种子条目为 1。`record` 以该技能档案（排除条目自身）测量，因此重复记录同一候选会保留其原始新奇度而非衰减为 0。
3. **档案即历史信号。** `mean(skill)` 报告技能的平均档案新奇度；均值下降正是 §31 所指的前沿停滞信号。适应度与新奇度的选择侧融合留在它原来的位置——优化器的幸存者选择；本包拥有持久档案，而非融合本身。
4. **一个持久域，一个命令面。** `evolution_novelty` 域（v1）含一张以候选 id 为键的 `archive` 表。`/novelty` 跨技能汇总档案并给出各技能均值，或列出某技能条目及其新奇度。本包挂载进 web-app profile（只写自己的域，不触及任何模型提示词）。

## 备选方案

- 把描述符放进优化器的实验账本——否决：账本记录的是每轮运行的结果；档案是跨运行的逐候选历史，且优化器包已把它对暂存写入的治理交给其他存储。
- 以优化器的按基线新奇度作为记录值——否决：该指标是单轮相对的；档案需要相对技能全部所见的新奇度，这是不同的、持久的信号。
- 基于嵌入的相似度——否决：harness 的进化族没有嵌入依赖，对规范化指令行做 Jaccard 无需模型调用即可确定性地测试。

## 后果

- 新奇度现在跨运行可测：`/novelty writer` 显示每次暂存写入相对技能此前全部所见有多不同，均值报告每技能的新奇度压力。
- 档案可查询：未来新奇度引导的选择（例如停滞恢复）可读取 `entries(skill)` 并按档案新奇度给候选排序（已在包的 Known Limitations 中记为暂缓）。
- 优化器保持解耦：记录可选且失败隔离，`descriptorOf` 是唯一的优化器新表面。

## 与计划的偏差

除常规外没有。档案测量时排除条目自身，使同一暂存写入的相同重复记录保持幂等；测试初稿断言的是原始 Jaccard 值而非 1 减它，在测量语义落定时被改正。

## 途中修复

除上述测试算术修正外没有。

## 测试

新奇度辅助函数：空集/不相交/重叠集合的 Jaccard 相似度、种子/空特征/最大相似度情形的档案新奇度、空与非空档案的均值。存储：种子记录满新奇度、重复记录排除、重叠与逐字描述符、技能隔离、列表排序/过滤/副本脱离、均值查询、经 zod 规范的重启持久化、启动前读取。优化器侧：`descriptorOf` 规范化、丢弃 frontmatter、空白正文、无 frontmatter 块正文；暂存胜者记录进已挂载档案、未挂载时暂存不变、失败存储记录警告。`/novelty`：未挂载、语法用法、跨技能档案汇总、按技能列出、空档案诚实文案。14 个新奇度搜索测试、3 个新优化器测试、4 个新命令测试通过；新包语句/分支/函数/行 100%，优化器保持 100%。

## 顺带不动

描述符由外部提供，而非包内推导：优化器在记录前从胜者正文提取特征行（包内 Known Limitations 有说明）。档案无上限增长；有界档案需要在域上加保留策略。这里没有融合逻辑——适应度与新奇度的结合仍是优化器幸存者选择中的选择侧行为。
