# Agent Note：基于种群（population）的进化

状态：已实现

[English](2026-09-21-population-based-evolution.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §51 将「基于种群的进化」列为 P1 #11：暂存的优化器写入应当累积成跨运行的、按技能组织的种群，让代数、谱系与已通过的精英足以指导技能保留什么，而不是让每次优化运行都成为孤岛、前一次胜者不带任何历史。优化器此前会暂存技能补丁，但没有任何持久的东西记住：哪个算子产生了哪个正文、它处于第几代、父代是谁、测得如何。

## 决策

新增一个包 `dsh-evolution-population`，持有带谱系与身份的候选：

1. **每次暂存写入都是一个候选。** 优化器在 `stageWrite` 之后立即通过可选存储缝记录每次暂存写入：候选 id 即暂存写入 id，连同算子、新颖度、测得的三元组与身份 `staged`。记录失败只记一条警告，绝不让优化失败（与 evolution-scorer 中 evaluator-health 记录器相同的可选挂载模式）。
2. **谱系自动且纯函数。** `record` 把同技能上一代头候选人接为父代，代数为该技能最高代数之后的一代（`nextGeneration`）。`lineageChain` 从最老祖先起沿 `parentCandidateId` 回溯，容忍悬空父代与环；`headOf` 挑最高代数、`at` 最新者打破平局，因此同代行确定性地解析。
3. **竞争即精英排名。** `rankElite` 按通过、然后更少 token、然后更快的墙钟时间给已通过候选排序；未测度候选排在一切已测度候选之下。`updateStatus` 让 `staged` → `approved` | `rejected`，终态永不离场。
4. **一个持久域，一个命令面。** `evolution_population` 域（v1）含一张以候选 id 为键的 `candidates` 表。`/population` 列出某技能的种群、回溯一条谱系，并批准或拒绝暂存候选。本包挂载进 web-app profile（只写自己的域，不触及任何模型提示词）。

## 备选方案

- 把种群放进优化器的实验账本——否决：账本记录的是每轮运行的结果；种群是跨运行的逐候选谱系，且优化器包已把它对暂存写入的治理交给其他存储。
- 把候选留在内存——否决：谱系与精英必须跨重启存活；按候选粒度的域才是持久归宿。
- 让优化器成为必需写入方——否决：可选缝让未安装种群包的部署行为完全不变，且失败存储路径不能破坏优化。

## 后果

- 优化历史现在可见：`/population writer` 显示代数、身份与精英，`lineage` 显示胜者的传承——运维者能分辨第一代 rewrite 与第十代 compress。
- 已通过精英可查询：未来的繁衍循环可以读取 `elite(skill)`，从它暂存下一代（已在包的 Known Limitations 中记为暂缓）。
- 优化器保持解耦：记录可选且失败隔离。

## 与计划的偏差

除常规外没有。头候选选择被抽成纯函数 `headOf`，以便同代行能在单元层面测试；服务的 `record` 自动排代，使同代行在其公开 API 下不可达。

## 途中修复

命令起初把动词（`approve`/`reject`）当作状态传给 `updateStatus`；现在命令把动词映射到存储的状态词汇（`approved`/`rejected`）。初稿在优化器上存了一个不存在的 `this.currentSkill`；现在技能被显式传入记录器。

## 测试

种群辅助函数：跨技能与陈旧行的代数编号、含悬空父代与环的谱系回溯、按代数再按 `at` 的头候选选择、按通过/token/墙钟时间的精英排名且未测度排在已测度之下。存储：自动父代与代数、头候选平局、空三元组、列表排序/过滤/副本脱离、代数查询、技能内谱系、精英、合法/非法/同状态/终态流转、未知 id、经 zod 规范的重启持久化、启动前读取。优化器钩子：已挂载存储记录暂存胜者、未挂载时暂存不变、失败存储记录警告。`/population`：未挂载、语法用法、种群列出、谱系（存在与缺失）、批准/拒绝含存储错误传播、注册与销毁。20 个种群测试、3 个新优化器测试、4 个新命令测试通过；新包语句/分支/函数/行 100%，优化器保持 100%。

## 顺带不动

竞争是排名，不是管线：尚无机制从精英繁衍下一代——这是后续基于种群驱动的改进循环（包内 Known Limitations 有说明）。候选是宿主全局而非按作用域键控；按作用域键控推迟。command-evolution 源码在未触及的命令中保留既有未覆盖分支（journey 导出的默认路径、curator 默认/错误路径），均早于本次工作。
