# Agent Note：金丝雀（canary）部署 / shadow 部署

状态：已实现

[English](2026-09-21-shadow-canary-deployment.md) | 中文

## 问题

`specs/evolutionary-harness-v11-deep-research.md` §51 将「shadow/canary 部署」列为 P1 #19，§18 给出发布方式：在对候选进行 canary 之前，先让它以 shadow 模式运行（与生产基线并置、隐藏响应），在不改变用户可见行为的前提下比较质量/成本/延迟，然后沿 shadow → canary → 渐进晋升推进。§49 补充人工介入规则（中风险 → canary）。Harness 此前对暂存技能补丁有审批治理，但没有任何东西追踪补丁的发布状态——哪些暂存写入仍是 shadow、哪些是 canary、哪些已晋升、哪些被拒绝或回滚。

## 决策

新增一个包 `dsh-evolution-canary`，持有带 shadow 证据的发布状态：

1. **只记录，绝不门控（§58.12）。** 优化器在暂存之后立即通过可选存储缝把每次暂存写入记录为 `shadow` 部署；不改变任何用户可见行为，记录失败只记一条警告，绝不让优化失败。强制仍是运维者通过 /canary 的审慎动作。
2. **发布状态机小而纯。** `nextStage` 走 `shadow → canary → promoted`；`transitionAllowed` 回答阶梯边与两个暂存退出边（`shadow → rejected`、`canary → rolled-back`）；终态永不离场，同状态调用无需写入即可解析。
3. **一个持久域，一个命令面。** `evolution_canary` 域（v1）含一张以暂存写入身份为键的 `deployments` 表，携带实测 shadow 三元组，`decidedAt` 只在终态决策落地时盖章。`/canary` 报告各状态（可选按技能）、推进一次发布（`rollout`、`promote`），或退出一次发布（`reject`、`rollback`）。本包挂载进 web-app profile（只写自己的域，不触及任何模型提示词）。

## 备选方案

- 给 population 存储加部署状态——否决：population 记录候选用于竞争（谱系、精英排名）；canary 记录带自身退出生命周期的发布意图，一包一生命周期让每个状态机小而可测。
- 复用 benchmark 的污染阶梯——否决：该阶梯治理评估（fresh → search → validation → holdout）；部署阶梯治理发布，其退出是 reject/rollback，不是污染。
- 让发布全自动——否决：§58.12 记录信任并呈现，而不是门控可见性；自动晋升是强制，不是追踪。

## 后果

- 发布状态持久且可检查：`/canary` 显示哪些暂存写入处于 shadow、canary 或 promoted，并附各自的实测三元组。
- 暂存补丁永远不会静默跳过阶段或逃离终态：未知 id 与非法流转响亮拒绝，重复的暂存写入 id 永不重新进入 shadow。
- 优化器保持解耦：记录可选且失败隔离，与 population、model-routes 记录器共享同一模式。

## 与计划的偏差

除常规外没有。命令为阶梯动词显式命名（`rollout`/`promote`/`reject`/`rollback`），而不是裸状态参数，以免运维者把状态名打错越过语法。

## 测试

状态：阶梯推进与终态停止、允许的阶梯与退出流转、禁止的跳跃、终态与跨退出、拓扑顺序。存储：带实测三元组的 shadow 进入、重复拒绝、空三元组、带 `decidedAt` 盖章的阶梯推进、暂存退出、终态不动、未知 id、同状态无操作、按阶梯顺序列出且带状态/技能过滤与副本脱离、按状态汇总且零从不省略、经 zod 规范的重启持久化、启动前读取。优化器钩子：已挂载存储把暂存写入记为 shadow、未挂载时暂存不变、失败存储记录警告。`/canary`：未挂载、跨全部动词的语法用法、带下一阶梯提示与技能过滤的状态列出、含存储错误传播的推进动词、注册与销毁。11 个金丝雀测试、3 个新优化器测试、3 个新命令测试通过；新包语句/分支/函数/行 100%，优化器保持 100%。

## 顺带不动

追踪不是强制：没有任何东西把技能对模型的可见性门控起来，且 shadow 测量是胜者的暂存三元组，而不是对照生产基线的隐藏响应比较——这种基于重放的比较是暂缓的监控工作（§18 的对比步骤，包内 Known Limitations 有说明）。部署是宿主全局而非按作用域键控；按作用域键控推迟。本包不触碰 memory 存储的审批治理，后者继续批准暂存写入。
