# Agent Note: P0-api/infra fixes batch 5

Status: implemented

English | [中文](2026-09-13-p0-api-batch-5.zh.md)

## Problem

Batch 5 of the full-sweep fixes (`docs/superpowers/specs/2026-09-13-full-sweep-fixes-design.md`) covered the api/infra chunk. Three findings were live defects with reproductions: newline-less stderr accumulation in the SDK client grew without bound, the gateway stream mux capped missed heartbeats with a hard-coded constant, and the frontend-static host re-read unchanged assets on every request. The rest of the batch's findings were either refuted by the code they named or pinned by a deliberate design, so they were triaged without a code change.

## Decision

The approval policy-fold cursor was implemented and verified during batch 4 and shipped in commit `6c28cc52a1`; it is summarized in the batch 4 note and listed here only because its finding belongs to the api/infra chunk.

1. `sdk/client/src/client.ts`: newline-less stderr accumulation capped at `STDERR_LINE_BUFFER_LIMIT` (64 KiB, newest kept). New `FAKE_STDERR_FLOOD_BYTES` harness + test (failed pre-fix with a 262,247-byte error, passes bounded).
2. `api/gateway`: `websocketHeartbeatMaxMissed` Config (schema default 2), threaded into `RemoteStreamMuxServer` replacing the `MAX_MISSED_HEARTBEATS` const; `startMux` helper + new maxMissed=1 test; Config-shape test extended; README + README.zh updated (both the knob row and the stale "terminated at the next interval" sentence).
3. `host/frontend-static/src/index.ts`: fiber-scoped stat-validated asset cache (100 entries, mtime+size key) with etag/304 conditional serving; index path stays dynamic and uncached. Two composition tests (etag round-trip, rebuild revalidation). Same-tick same-size rewrite staleness documented in code.

## Alternatives considered

**Fix the reported gateway lost wakeup.** Refuted: the waiter is assigned synchronously in the Promise executor with no await/yield between the empty-check and the assignment (run-to-completion), and each queue has exactly one consumer (`yield*`, index.ts:424), so no interleaving exists.

**Harden `methodParameterNames` against minification or definition rewriters.** Accepted constraint instead: the SRC fallback is the only path (strict Typert definitions bypass it), it fails loud with a directing message, the signature-invalid tests pin it, and the tsdown build does not minify. Generator metadata would be a redesign.

**Invalidate `srcClaims` more eagerly.** Refuted: `internal/service` fires from Cordis `reflect.ts:333` on service implementation changes, which covers provide/dispose; strict definitions bypass the cache anyway, and dispatch re-resolves fresh — residual staleness is fail-safe in both directions.

**Re-parse or copy on anchor mutation.** Refuted: `parsePatchList` parses fresh objects per call and the file:// anchoring is idempotent over a single base.

**Re-key patch provenance to survive mid-list inserts.** Accepted limitation instead: the index diff misattributes only if mid-list inserts occur, and `--dump-config` is debug output with no behavior impact.

**Snapshot the permission-preset labels instead of reading live defaults.** Consistent by construction as shipped: enforcement (`tool-bash:169`, `tool-pwsh:181`) reads the same live defaults, so the labels always match effective behavior.

**Quarantine the schedule latch on a fold error.** Accepted containment instead: the latch is fail-safe by the schedule package's stream-is-the-only-state rule — quarantine would silently drop reminders — and fold errors name the record.

**Guarantee wakes against `requestDrive` coalescing.** Accepted containment instead: coalescing cannot starve wakes, because each drive re-arms the nearest target.

**Exclude stopping jobs from the quota.** Accepted containment instead: stopping still holds resources, and teardown force-failure covers wedged stops.

**Replace the `home` protocol field with an opaque id.** Not a P0 fix: `home` is load-bearing (loopback detection, picker defaults, pinned tests).

**Tighten vm/timer trust, inspector capture, `.env` precedence, or credential reload.** Accepted designs instead: the vm/timer trust stance is documented in-module, the inspector is a local-debug tool, inherited env wins by documented precedence, and reload warn-and-keep is the deliberate fail-safe mirror of settings-file.

**Change boot-time sync FS reads, RPC scans, `MIN_EVERY`, the release timeout, or preset silence.** Accepted as is: one-time small-file cold-start reads; tiny-n scans with fresh dispatch; 300s is an abuse-protection floor in pure domain math (the package has no Config surface by design); fatal-path timing; resolution-time fail-loud already covers the preset default case.

## Consequences

Stderr accumulation is bounded to the newest 64 KiB, the heartbeat-miss bound is deployment configuration (default 2) rather than a constant, and frontend-static serves unchanged assets conditionally while the index path stays dynamic. Two limits stay by design: the asset cache can serve stale bytes for a same-tick same-size rewrite (documented in code), and index-diff patch provenance can misattribute when mid-list inserts occur, which only affects debug output. Every finding the batch declined to change keeps its documented behavior, with the trade-off recorded beside it in Alternatives considered.
