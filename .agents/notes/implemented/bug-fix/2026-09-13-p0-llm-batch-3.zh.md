# Agent Note: P0-llm fixes batch 3

Status: implemented

[English](2026-09-13-p0-llm-batch-3.md) | 中文

## Problem

`docs/superpowers/specs/2026-09-13-full-sweep-fixes-design.md` 记录的全量扫描评审在 llm 相关面提出了若干 finding，该扫描的批次 3（日期 2026-09-13）对其逐一处置。其中三个 finding 属于真实缺陷或缺失的决策记录，作为代码变更落地于 `llm-retry/src/index.ts`、`llm/src/assembler.ts` 与 `command-goal`；其余七个按 Alternatives considered 中记录的理由驳回，读者无需重开评审即可知道它们为何保持现状。

## Decision

三个 finding 作为代码变更落地：

1. `llm-retry/src/index.ts`：四条裸 `return` 中止路径现在显式返回 `undefined`，并各配一行注释说明被拒绝的条件。零行为变化；现有取消测试（retry.spec.ts:953, 976）锁定该语义。
2. `llm/src/assembler.ts`：类 JSDoc 记录分层契约——挂载 `llm-invariant` 时它对畸形流严格抛错，未挂载该依赖的组合中 assembler 保持 total。仅注释。
3. `command-goal`：本地 `assertNever` 替换为共享的 `@deepseek-ai/dsh-util-values` 导入（外加 `dependencies` 条目与 `tsconfig` reference）。本地消息格式由共享的 `unreachable variant in <context>` 格式取代；没有测试锁定旧文本。

## Alternatives considered

**让 `always` 不再吞掉下游决策。** 已证伪：`RequestErrorAction` 是封闭联合 `{ kind: 'retry' } | undefined`（`core/agent/src/runtime-types.ts:122`），不存在该 finding 能命中的 fail/abort kind。先拒绝再重试是设计中的组合，由 `retry.spec.ts:728,751` 锁定，且 llm-fallback 决策（`.agents/notes/implemented/feature/2026-09-11-llm-fallback.md:25`）已把 always 使 fallback 饿死记为可接受的 trade-off。

**给 `always` 加上界。** 已有记录：policy 接口、`llm-retry` README（cost 归属与 `llm/retry` 指标）以及 `keeps always mode unbounded` 测试三者一致，加上界等于与三处已记录的范围声明相矛盾，而不是修补缺口。

**让 `translate` 对空 id/name 严格。** 属已锁定的容忍：`translate.spec.ts:331` 有意锁定面向宽松网关的空字符串回退，而空 name 会在工具分发处 LOUD 失败（unknown tool），从不静默。严格化会为一个并不存在的静默失败牺牲网关兼容性。

**用显式 quanta 取代 `?? 1` 默认值。** 属已接受的 trade-off：所有生产构造器都显式传入 quanta 或采用 identity 默认值，且该纯函数记录了确定性。为 3 个 provider 连同测试与 `.d.ts` 镜像做接口改动，买不到任何可观测收益。

**在 `dsh-foreign` replay 中对异源历史抛错。** 属有意设计：`foreignAssistant`（`llm-pi-ai/src/replay.ts:153`）的存在目的就是转换历史而不把它当作同模型 replay 来信任，抛错会破坏跨 provider replay。

**把进程内 breaker 改为跨进程。** 已有记录：模块 JSDoc、README 正文与 `## Known Limitations and Deferred Work`（"Process-local breaker"）都写明进程内范围，该 finding 只是复述已记录的行为。

## Consequences

四条显式 `undefined` return 不带来行为变化，取消语义仍由现有测试锁定。assembler 的分层契约是记录而非强制，因此未挂载 `llm-invariant` 的组合仍保留 total assembler。`command-goal` 的本地 `assertNever` 文案让位于共享的 `unreachable variant in <context>` 格式，没有测试需要更新。被驳回的 finding 让行为完全保持已记录的样子——无上界的 `always` 使 fallback 饿死、宽松的 `translate` 网关、identity 默认 quanta、容忍异源历史的 replay，以及进程内 breaker——而增量式 SSE 发送的重构另行跟踪（见 Deferred）。

## Deferred

SSE `block-end` 批处理推迟到批次 7。增量发送是需要先做 TTFT 度量的重构，而不是 bug fix：它转 P1 并附带度量要求。
