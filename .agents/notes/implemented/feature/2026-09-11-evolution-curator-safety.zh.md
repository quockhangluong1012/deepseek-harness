# Agent Note：演进式整理器安全——快照、台账与失败关闭的回滚

Status: implemented

[English](2026-09-11-evolution-curator-safety.md) | 中文

## 问题

自动通过改变生命周期状态后无法回头：错误的阈值或误触发的计划会静默归档技能，而试运行预览只展示移动，没有任何关于落子内容的持久证据。规范以每次通过的 tarball 备份、带内容寻址 blob 的只增 JSONL 台账，以及整轮加单条目回滚作答——全程无需模型参与，因此安全切片可先于合并交付。

## 决策

以 `src/safety.ts` 扩展 `@deepseek-ai/dsh-evolution-curator`，挂三个服务方法。有移动的真实通过写一个 tarball（`snapshots/pass-<时间戳>-<id>.tar.gz`，修剪到 `backup.keep`），暂存前后记录对、可解析的技能目录与清单，然后向只增 JSONL 台账追加一条 `pass` 条目加每次移动一条 `transition` 条目，记录 blob 按内容寻址存储。`rollbackPass` 与 `rollbackEntry` 只恢复生命周期状态——永不碰文件——先验证全部记录与 blob，先快照当前记录使每次回滚可逆，并为每个技能记一条 `rollback` 条目。未知标识、缺失 blob、未跟踪技能与缺失存储都在一切写入之前失败。不可解析的目录进入通过证据，而不是失败。快照由 npm `tar` 包支撑：一个受维护的依赖，删掉约百行自有归档格式代码及其测试。

## 备选方案

- **基于 `node:zlib` 手写 tar。** 按依赖优先于手写规则否决：受维护的 `tar` 包（已在安装闭包中、ESM、无安装脚本）删掉约百行自有格式代码及其测试。
- **从 tarball 恢复技能目录的回滚。** 否决：流转永不碰文件，恢复目录会覆盖用户后来的编辑。tarball 留作审计证据，直到文件系统那次通过移动目录；回滚经由 `setState` 重打状态，按其自身不变量重盖 `archivedAt`。
- **经由新遥测写入的全记录恢复。** 否决：blob 可能早于更新的使用/查看计数，全量恢复会覆盖更新的观测。仅状态恢复不碰计数与置顶。
- **对含不可解析目录的通过跳过快照。** 否决：记录已经变了，需要证据。缺失目录解析为 `undefined` 并进入通过证据；tarball 保留记录与清单。
- **把时钟与家目录覆盖做成配置。** 否决：时钟已随调用到达，harness 家目录经由 `$DSH_HOME` 解析、测试按 worker 重定向。无测试钩子，模式中不烘焙机器相关默认值。

## 后果

每次真实通过如今可逆可审计：状态界面列出通过及其快照与流转计数，操作者可回滚整轮或单条目，每次回滚自身的前后 blob 让链条可继续追溯。`dryRun`、空通过与备份关闭的通过什么都不写。台账损坏在读取时大声失败，而不是回滚错技能。

## 测试

十一个安全用例锁定：目录解析、哈希、带未解析名单的快照内容、keep-N 修剪、台账往返与畸形行失败、真实通过的快照与 tarball 内容及通过列表、整轮与单条目回滚与重盖戳、未知标识/缺失 blob/未跟踪技能/损坏证据的失败关闭、无存储拒绝、新家目录读取——另有十一个沿袭的流转用例。按文件 100% 在语句、分支、函数与行上成立。
