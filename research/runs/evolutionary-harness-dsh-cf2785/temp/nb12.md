# Curator lifecycle (evolution-curator)

Primary source: `packages/evolution/evolution-curator/src/index.ts` + `specs/evolutionary-harness.spec.md` (Curator section).

Host-wide single timer (`tickMinutes` 15) with a start-time due check; a pass runs only when enabled, `intervalHours` 168 elapsed since `lastRunAt`, and `minIdleHours` 2 of observed idleness (a host with no activity counts as idle). First call seeds `lastRunAt` and defers one interval.

Automatic transitions `active → stale (30d) → archived (90d)` into `.archive/`, skipping pinned, protected, schedule-referenced, bundled/hub skills; never-used skills get grace from creation. `dryRun` previews without writing; `archiveAfterDays < staleAfterDays` fails loudly.

LLM consolidation is opt-in (`consolidate: false`): surveys `createdBy == 'agent'` skills, records a cost ledger row, runs a bounded in-package loop (`maxSteps` 4) over view/apply tools with keep/patch/consolidate/archive verdicts under the full-package rule. Backups are per-pass tarballs (keep 5); JSONL ledger is content-addressed; whole-pass and single-entry rollback are reversible; `adopt` is manual; `purge` only removes archived skills past TTL (default 0 = never); `pin` blocks transitions and managed deletion.
